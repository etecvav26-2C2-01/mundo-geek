# 🌏 Mundo Geek
Repositório destinado ao projeto mundo geek, um e-commerce fictício destinado ao nicho geek. O projeto utiliza:

- HTML5
- Bootstrap 5
- PHP
- MySQL
- Git/Github

---

# 🎯 Objetivos 

A proposta inicial do site é:

- Apresentar o catálogo do projeto; 
- Dispor funcionalidades administrativas;
- Funcionalidades como carrinho;
- Aprsentar descrição detalhada dos produtos;
- Venda dos produtos geek;
- Serviço de entrega
